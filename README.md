# 冰星創思｜電商費用試算器

單一 HTML 的電商費用／利潤試算工具，目前支援蝦皮、露天、Yahoo 奇摩拍賣與銀角零卡。

## 📁 從最舊到最新的版本

所有原始碼依版本分別歸檔於 [versions](./versions/) 資料夾。從 V0.1 到 V3.2 的逐版功能新增與修改，請查看：

**[CHANGELOG.md｜完整版本更新紀錄](./CHANGELOG.md)**

**最新維護註解版：[V3.2 HTML](./versions/v3.2.html)**

> V0.1～V3.2 共 32 個歷史版本均已收錄，包含 V1.9。

## 如何使用

1. 開啟 `versions/v3.2.html`，點選下載原始檔（Download raw file）。
2. 用 Chrome、Edge 或其他現代瀏覽器開啟 HTML。
3. 切換平台、輸入售價／進價等資料，按試算即可；不需安裝套件，也不需架設伺服器。

可用 Sublime Text 閱讀、修改 HTML/CSS/JavaScript；一般使用者只需用瀏覽器開啟。

## 維護注意

- 費率是依開發階段提供的資料建立，**不保證等於平台當前收費**；實際費率以平台最新公告為準。
- 對外公開前，需逐平台驗證計算公式、付款方式、歷史紀錄還原、手機排版與字級設定。
- 試算歷史僅儲存在該瀏覽器本機，不會傳到 GitHub。
- **目前 Repository 設為 Private，尚未啟用 GitHub Pages。**
- 建議新增版本時不要覆蓋原版，並同步更新 `CHANGELOG.md`。
